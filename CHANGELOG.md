# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This project does not yet publish versioned releases; entries are grouped under
`[Unreleased]` until a versioning scheme is adopted.

## [Unreleased]

- **Facility Excel export now carries trainee, coach & staff numbers and contact details.** The filtered-facilities export gains, per facility: **Total Trainees / Trainees (Male) / Trainees (Female) / Sanctioned Strength (Trainees)** (from the facility's own record — populated for 237 facilities, and exactly reconciling with the per-discipline trainee sums), **Coaches (Sanctioned) / Coaches (Current) / Total Staff (Sanctioned) / Total Staff (Current)** (aggregated from the manpower table by `Facility_ID` — a coach is any designation containing "coach"; ~33 KISCE facilities carry staff data, the rest stay blank rather than a misleading 0), plus **Operational Status / In-charge / Contact Person / Contact Number / SAI Region**. Absent numbers render blank; a real 0 (e.g. sanctioned coaches with none currently in position) is kept. `exportFacilitiesToExcel` now takes the manpower rows; Projects export is unchanged.
- **Facility Excel export now includes a Sports Disciplines column.** The filtered-facilities export gains a **Sports Disciplines** column (between *Facility Name* and *Coordinates*) listing each facility's disciplines taken verbatim from its own `Disciplines` field — the same source the Sport filter matches on, so the column and the active discipline filter always agree. Non-sport placeholder rows (e.g. *Yet to be Started*) are dropped to match how the platform elsewhere treats disciplines; Para variants are preserved as-is. Populated for 1,191 facilities (85 have no discipline data → blank). Projects export is unchanged (disciplines are a facility concept).
- **Filter facilities by sport discipline.** The filter panel gains a **Sport** dropdown (`DisciplineSelectDropdown`) — a custom icon dropdown listing every discipline offered across facilities, each with its sport emoji (`getDisciplineIcon`). Para variants are collapsed to their base sport (e.g. *Athletics-Para* → *Athletics*) and junk rows dropped, so "Athletics" matches facilities offering either. Selecting a sport filters the **Facilities** map markers to those offering it, combines (ANDs) with the State and Facility Type filters, and feeds the existing count + Excel-export strip (the discipline name is added to the export filename hint). The dropdown is hidden while the Projects (PRJ) layer is active, since disciplines are a facility concept. New reusable `baseDiscipline()` helper in `lib/disciplineIcons.ts`.
- **Filtered count + Excel export (facilities *and* projects).** When a filter is active, a strip appears below the search box showing the **matching count** and a one-tap **Excel** download of exactly the filtered rows. It adapts to the active layer: **facilities** export *S.No / Facility Type / Facility Name / Coordinates / Address*; the **Projects** layer exports *S.No / Project Code / Project Name / Infrastructure Type / Status / Progress / State / District / Coordinates / GPS Images Pending* (honouring the combined Status + Without-GPS filters — e.g. the 33 completed-without-GPS projects). `xlsx` (SheetJS) is **dynamic-imported** in `lib/exportExcel.ts`, so it's code-split into its own chunk and only loaded on the first export — the initial bundle is unaffected. (`xlsx` moved from dev- to regular dependencies.)
- **Real project status + progress %.** A new progress workbook drives each project's `Status` (270 Completed / 76 In Progress / 27 Cancelled) and `Progress` (0–100): Completed ⇒ 100%, Cancelled ⇒ none, everything else ⇒ In Progress with its real %. The **Overview tab shows a progress bar + %** (and the popup shows the %). Pipeline: `scripts/build_project_status_overrides.cjs` + `apply_project_status.cjs` — the source→platform mapping is two small isolated functions, so re-running with an updated workbook is all that's needed later.
- **"Without GPS Images" is now an independent filter that combines with status.** The project filter bar is split into a single-select **Status** row (`In Progress`/`Completed`/`Cancelled`) and a separate, dashed **"Without GPS Images"** toggle on its own line; the two **AND** together — e.g. *Completed + Without GPS Images* shows the 33 completed projects still needing GPS-verified photos. (`Without_GPS_Images` stays independent of status in the data — the status pipeline never touches it.)
- **Satellite basemap on by default** — the app now opens in satellite view (`satellite` state initialised `true`). Toggle it off from the search box as before.
- **Mobile minimize pull-tab.** On mobile/tablet the filter panel now minimizes via an **animated glowing pull-tab** protruding at its bottom edge (a pulsing glow ring + a gently-bobbing chevron, `prefers-reduced-motion` respected) instead of a small in-field button, and the panel itself is more compact. Tap it to collapse to the two circular buttons; tap the search button to expand.
- **Mobile / tablet UX overhaul (≤1024px).** The app is now touch-first on small screens (new `lib/useMediaQuery.ts` → `useIsMobileOrTablet()`): (1) the floating filter panel moves to the top, drops its results downward, and **auto-minimizes to two circular buttons** (reopen search + zoom-to-map reset) after a search — tap to expand; the drag grip becomes a minimize button. (2) The Facility Type control swaps from the icon-chip row to a proper **icon dropdown** (`TypeSelectDropdown.tsx`) so every type shows an icon *and* a full label. (3) The state report card becomes a **bottom sheet** — slides up from the bottom, half-screen with a scrollable body, and a grab handle expands it to near-full. Desktop (>1024px) is unchanged.
- **Search projects by Project Code.** The filter-panel search now also matches a project's `Project_Code` (case-insensitive, partial — e.g. `AP001` or `rj04`), alongside the existing name/state/district matching; the code is shown in each project result's meta line so a code match is visible.
- **Projects in the state report card.** Clicking a state now shows its **project count** in the report's overview line ("… • N facilities • M projects"), and a new **Projects** section at the end lists every project in that state. Each project name is clickable — it closes the report and flies the map to that project in **birdeye view** (Projects layer shown, aerial close-up at zoom 17), reusing the same `BIRDEYE_ZOOM` as the popup Birdeye action.
- **"Zoom to full map" button + refreshed satellite icon.** The search box's satellite toggle now uses a proper orbiting-satellite icon (solar panels + dish + signal) instead of the old generic layers glyph. A new fit-to-extent button appears in the search row *only* once the map is zoomed in past the all-India overview (`ZOOM_TO_MAP_MIN_ZOOM = 6`) — the search field narrows to make room and widens back when it hides, adjusting live on zoom in/out; clicking it flies back to the overview. It's wired so MapView reports only threshold *crossings* to App (`onZoomedInChange`), so panning within a zoom band never re-renders the panel (viewport-state invariant preserved).
- **Satellite declutter + Birdeye.** In satellite mode the state choropleth overlay now fades out entirely between zoom 6→7 (linear, via a zoom-interpolated `fill-opacity` expression) so zoomed-in imagery is unobstructed, and returns on zoom-out; past the fade the invisible state layer also stops intercepting hover/click (no phantom "Click to filter state" tooltip). Street mode is unchanged. The facility popup's Overview tab **and the project (PRJ) popup** each gain a **Birdeye** button beside Directions: it closes the popup and flies the map straight down to that facility/project at zoom 17 — an instant aerial close-up on the satellite basemap.
- **Satellite view.** A layers-icon toggle inside the filter panel's search box switches the basemap to Esri World Imagery satellite tiles with Esri's Boundaries & Places raster overlay for readable place names (hybrid view) — no API key, required attribution surfaced via MapLibre's attribution control, tiles fetched per-viewport so only India imagery is ever downloaded, always current from the provider. While active: the state choropleth tint drops to 5 % (30 % hover) so imagery stays legible, state/district boundary lines switch to white, and the light/dark toggle hides (it only affects the CARTO street styles). Markers, clustering, popups, click-to-filter and 3D mode all work unchanged on the satellite basemap. `satellite` state lives in `App` (the control is in `MapFilterBar`, the map in `MapView`). Note: OpenStreetMap publishes no satellite imagery — Esri World Imagery is the standard free companion layer used with OSM-based maps.
- **Real project GPS coordinates** (from the final "Project coordinates final.xlsx" source, whose two sheets are disjoint and cover all 373 projects). **262 projects** get exact `Latitude`/`Longitude` + `Google_Maps_URL` from the "Projects With Image Coordinates" sheet (coordinates parsed from each row's Google Maps Link, cross-checked against the row's own Coordinates column, or the pipeline aborts) with `Without_GPS_Images: false`. The other **111** (the "Projects Without Coordinates" sheet) **keep their existing location** (e.g. an earlier interim/approximate one) untouched, and are instead explicitly flagged `Without_GPS_Images: true` — a permanent, data-driven marker that they still need GPS-verified site photos, independent of whatever coordinate they carry. 3 codes in the source (`RJ046/047/048`) aren't in the dataset and were reported, not fabricated. New `scripts/build_project_gps_overrides.cjs` + `apply_project_gps_coordinates.cjs` (same provenance pattern as the facility coordinate overlay, surgical — an override only touches the fields it actually specifies); `Project` gained `Google_Maps_URL` and `Without_GPS_Images`.
- **Dedicated Projects (PRJ) GIS layer.** Projects are now their own independent, clustered map layer with premium violet status-coloured markers at their own coordinates (`ProjectLayer`), a project-centric popup (`ProjectPopup` — no facility/NCOE reference) and a project-centric detail modal (Overview / **Financials** / Timeline / Gallery / Documents / Remarks). The left sidebar is replaced by a floating bottom-left **`MapFilterBar`** (Facility Type dropdown, State selector, **PRJ layer toggle**, intelligent search over facilities + projects). Facility and PRJ layers filter/toggle independently; search results "Show on Map" fly to the PRJ marker and open its popup. (Removed the NCOE-linked `ProjectsModal`, `FilterPanel`, and the `USE_PROJECT_COORDINATES` flag.)
- **Phase-1 Sports Infrastructure Projects module.** 373 projects from the "Project mapping" Excel, each associated with a parent facility of its state (largest NCOE, else largest facility). New `📋 Project Details →` popup link → state Projects modal (total + infra breakdown + sort + cards) → per-project detail modal (Overview / Gallery / Documents / Timeline / Remarks). Gallery with placeholder + image upload (drag-drop / multiple / camera, stored by Project Code in a separate IndexedDB) and an in-platform fullscreen viewer (prev/next/zoom/pan/download/delete/close). Architecture is ready to switch to real project coordinates via a single `USE_PROJECT_COORDINATES` flag. New: `scripts/convert_projects.cjs`, `src/lib/{projects,imageStore,permissions}.ts`, `src/components/Modal.tsx`, `src/components/projects/*`.
- Facility coordinate updates from the source Excel (208 non-KIC + 795 KIC facilities set to exact coordinates + Google Maps URLs); `📋`/`🧭` Directions button in the popup. (`scripts/{build_coordinate_overrides,apply_coordinate_updates}.cjs`.)
- Map polish: pin hover box (name + type), larger NCOE pins, hovered marker raised above neighbours.
- Project documentation set for long-term maintenance: `CLAUDE.md` (project context + coding/workflow rules), `docs/architecture.md` (canonical up-to-date architecture reference), `docs/roadmap.md` (forward plan + known issues), and this `CHANGELOG.md`.

### Changed
- **Filter panel and quick chips merged into a single widget; the "All Facilities" dropdown is gone.** The Facility Type selector (the icon dropdown) is removed — the quick-filter chips (`MapQuickChips`, now nested inside `MapFilterBar`'s panel) are the sole Facility Type control, and are no longer a separately positioned/draggable bar. One grip handle (in the search box) now drags the whole panel — search, State, chips, and the Projects status row all move together; there's a single remembered position (`localStorage` key `mapFilterPanelPos` — the now-unused `mapQuickChipsPos` key is simply no longer written). Chips wrap onto multiple lines inside the panel instead of scrolling horizontally, and each carries the full type name as a hover tooltip (e.g. "National Centre of Excellence") so that information isn't lost with the dropdown. Removed the now-dead `FILTER_CHIP_CATEGORIES` export and all `.type-select*`/`.map-quick-chips` CSS.
- **"Without GPS Images" now shows exactly the flagged projects, with a per-project "Coordinates available" opt-out.** `projectMatchesStatusFilter` (`lib/projects.ts`) matches a project that is explicitly flagged `Without_GPS_Images: true` by the source data (the 111 without a confirmed location) **and** that the user hasn't marked "Coordinates available" — so clicking the filter shows those 111 on the map (previously it also matched any project with zero uploaded photos, i.e. everything in a fresh session). A new **"Coordinates available"** toggle in a flagged project's **Gallery tab** (`CoordinatesAvailableToggle` in `ProjectDetailModal`) removes it from the filter; the confirmation is stored in a new `coordConfirmations` table in the reseed-surviving `ProjectImages` DB (`lib/imageStore.ts`), so it sticks across data refreshes and reloads, and the map updates reactively (`useLiveQuery`). Reversible. (Replaces the earlier photo-count-based logic; `projectCodesWithImages()` removed.) Verified end-to-end: filter shows 111 → marking one "Coordinates available" drops it to 110 and persists across reload → undo restores it.
- **Smaller location pins (~30%).** Facility/PRJ pins (`MapPinGraphic`) reduced 34×46 → 24×32; KIC's own teardrop 32×32 → 22×22. The embedded discipline-emoji badge and type-acronym text on KIC pins are scaled more gently (~20%/~12%) than the pin frame so they stay legible at the smaller size. NCOE's existing 1.3×/1.55× (hover) size multiplier and the PRJ hover-pulse ring are recalibrated to the new base so the established visual hierarchy (NCOE bigger; pulse centred on the pin head) is unchanged, just smaller overall. Cluster bubbles are intentionally left as-is — they represent a count, not a single location, and staying larger than an individual pin reinforces that hierarchy.
- **Draggable floating widgets + panel reorder + regrouped quick chips.** The quick-chip bar and the filter panel each have a grip handle (start of the chip row; end of the search box) and can be dragged anywhere on screen — position is clamped to stay fully on-screen and remembered per-browser (`localStorage`, keys `mapQuickChipsPos`/`mapFilterPanelPos`); double-click a handle to reset to the default bottom-left spot. New `src/lib/useDraggable.ts` (pointer-events based, touch-safe) + `src/components/DragHandle.tsx`, reused by both widgets. Panel order is now Search → State → Facility Type (State moved above the type selector). Bottom quick chips now show `All/NCOE/STC/KIC/RC/Projects` primary with `KISCE/EXT/AKH/IGMA/NSTC` behind "More Filters" (was `NCOE/STC/KIC/NSTC/IGMA/RC` primary + `KISCE/EXT/AKH` more).
- **Redesigned floating filter panel & unified type selector.** The bottom-left `MapFilterBar` is now a glassmorphism panel (blur, translucency, soft shadow, rounded corners): global search (facilities + projects + districts), a custom **Facility Type selector** (icon dropdown covering all 9 facility types + "All Facilities" + "Projects (PRJ)", doubling as the map legend), a **Project Status filter** (`In Progress`/`Completed`/`Cancelled`/`Without GPS Images` — shown only when Projects is selected), and a compact State selector. A new **`MapQuickChips`** bottom bar gives one-tap access to the most-used types plus a "More Filters" expander. Facility Type/Projects selection is now a single unified, Google-Maps-style choice — selecting a specific type or Projects shows only that layer; "All Facilities" shows both. The static top-left type legend is removed (marker colours/icons and the selector/chips are the legend). New: `src/components/{MapQuickChips,TypeIcon}.tsx`; `lib/imageStore.ts` gained an index-only `projectCodesWithImages()` query. Removed: the standalone PRJ-layer checkbox toggle, `FILTER_CHIP_CATEGORIES`'s previous 7-type subset (now all 9), and ~150 lines of dead sidebar/stats CSS left over from earlier redesigns.
- **Premium pin icon set.** Markers now use a consistent teardrop frame with a white type glyph — building (RC), trophy (NCOE), runner (STC), columns (EXT), institution+star (KISCE), handshake (AKH), crane (Projects) — via the shared `MapPinGraphic`. The facility-type palette (`FACILITY_CONFIG`) was updated to the reference colours (NCOE green, STC orange, EXT purple, AKH gold; Projects navy), which flows to the legend, popups, search dots and report-card chips. **KIC keeps its original look** — the classic purple (`#8e24aa`) teardrop showing the facility's sport icon (or the "KIC" acronym where there is no single sport). Replaces the earlier acronym labels (for all other types) and the STC/EXT/AKH silhouette shapes.
- Sidebar now shows all 7 facility-type filter chips (RC/NCOE/STC/EXT/KIC/KISCE/AKH).
- Statistics Overview removed from the sidebar (`StatsDeck` deleted; Recharts no longer bundled); trainee-strength breakup moved beneath the total in the right-side state report card.

## Baseline (current state of `main`)

The application as it stands at the start of changelog tracking:

- Interactive MapLibre map of 1,277 SAI facilities (React 19 + TypeScript 6 + Vite 8), fully client-side with data in IndexedDB (Dexie); no backend.
- Marker clustering via `supercluster`; 3D state extrusion and dark-basemap toggles.
- State choropleth tinted by SAI region with hover highlight and click-to-filter (with GeoJSON ↔ data state-name aliasing).
- Filter panel: facility search typeahead, Region/State/Discipline selects, facility-type quick chips, active-filter tags + reset.
- Statistics deck: animated count cards, gender split bar, "Top 5 Disciplines/States" and "Gender by Facility Type" charts (per-discipline aggregation).
- Per-facility popup (Overview / Disciplines / Funds & Staff) and per-state report card (facility mix, trainees + utilization, disciplines, KISCE funds by FY, staffing, top facilities).
- Single-source facility taxonomy (`lib/facilityTypes.ts`) driving pins, chips, cards, legend, and charts.
- Build-time Excel → JSON pipeline (`scripts/convert_data.js`) with a `meta.json` version stamp that drives client reseed.
- PWA via `vite-plugin-pwa` (service worker + web manifest).
